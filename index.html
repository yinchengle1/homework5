Riemann and Lebesgue Integration

Two perspectives on the integral

Riemann Integration

The Riemann approach partitions the domain into small intervals. The function is evaluated at selected points, and the resulting rectangles approximate the area under the curve.

∫ₐᵇ f(x) dx ≈ Σᵢ f(xᵢ*) Δxᵢ

For equally spaced subdivisions, the midpoint approximation is:

Rₙ = (b − a)/n · Σᵢ₌₀ⁿ⁻¹ f(a + (i + 1/2)(b − a)/n)

Lebesgue Integration

The Lebesgue perspective partitions the range of function values instead of partitioning the domain. For each range interval, we measure the set of points whose function values belong to it.

∫ f dμ ≈ Σⱼ yⱼ · μ({x : f(x) belongs to range bin j})

For a finite range partition, the integral is approximated by multiplying each representative function value by the measure of its preimage.

Pathological Functions

Examples where Riemann and Lebesgue theory differ

Dirichlet Function

f(x) = 1 if x is rational; 0 if x is irrational

Every interval contains both rational and irrational numbers. Consequently, the Dirichlet function is discontinuous everywhere and is not Riemann-integrable.

However, the rational numbers have Lebesgue measure zero. The function is therefore Lebesgue-integrable, and its integral is zero.

Theoretical Lebesgue integral: 0. A numerical grid containing only rational sample points may misleadingly produce an average of 1. This illustrates why naive point sampling cannot determine the Lebesgue integral of this pathological function.

Thomae's Function

f(p/q) = 1/q for reduced rational p/q; f(x) = 0 for irrational x

Thomae's function is continuous at every irrational point and discontinuous at every rational point. It is Riemann-integrable on [0, 1], with integral zero.

The function also has Lebesgue integral zero. Rational values with small denominators occur at only finitely many points for each fixed denominator bound, while all remaining function values can be made arbitrarily small.

1. Definition of the Normal CDF

The standard normal probability density function is:

φ(x) = (1 / √(2π)) exp(−x² / 2)

Its cumulative distribution function is:

Φ(x) = ∫₋∞ˣ (1 / √(2π)) exp(−t² / 2) dt

There is no expression for this antiderivative using elementary functions. Nevertheless, it has an exact representation using the special error function.

Why the Normal CDF Is Not Elementary

Liouville's theorem and special functions

1. The Mathematical Problem

The normal CDF involves the integral of the exponential of a negative quadratic polynomial:

∫ exp(−x²/2) dx

Unlike many elementary integrals, this expression cannot be written using a finite combination of elementary functions: polynomials, rational functions, exponentials, logarithms and trigonometric functions.

2. Liouville's Theorem

Liouville's theorem in differential algebra gives necessary conditions for an elementary antiderivative to exist. In simplified terms, an elementary antiderivative must be expressible through a finite combination of algebraic functions, exponentials, logarithms and derivatives of such functions.

For the integrand exp(−x²), the required elementary antiderivative does not exist. This is a classical consequence of Liouville's theorem, often formulated through the Risch algorithm and differential algebra.

The result does not mean that the integral cannot be calculated. It means that an elementary closed-form antiderivative is unavailable. Special functions provide a natural exact notation.

3. The Error Function

The error function is defined as:

erf(x) = (2 / √π) ∫₀ˣ exp(−t²) dt

Using this special function, the standard normal CDF can be written exactly as:

Φ(x) = 1/2 [1 + erf(x / √2)]

This is an exact analytical representation, but practical computers still need numerical algorithms to evaluate erf.

4. Power Series Expansion

The error function has the convergent series:

erf(z) = (2 / √π) Σₙ₌₀∞ [(-1)ⁿ z²ⁿ⁺¹ / (n!(2n+1))]

The series can be evaluated term by term. For large absolute values of z, however, convergence and cancellation may make other numerical methods more efficient.

5. Numerical Methods

Simpson's Rule

Approximates the integral using quadratic interpolation. It is generally more accurate than the trapezoidal rule for smooth functions.

Trapezoidal Rule

Approximates the area using trapezoids. It is simple, stable and easy to implement.

Power Series

Evaluates the error function using its mathematical series expansion. The number of terms controls the approximation accuracy.

Fast Approximation

Uses a polynomial approximation to the error function. It is computationally efficient but introduces a small approximation error.

Conclusions

Main observations from the experiments

Riemann Integration

Domain partitioning works well for continuous and piecewise continuous functions. Accuracy improves as the partition becomes finer.

Lebesgue Integration

Range partitioning provides a different perspective based on preimage measures. It is particularly useful conceptually for understanding measurable functions.

Pathological Functions

Dirichlet's function is not Riemann-integrable but is Lebesgue-integrable. Thomae's function is integrable in both senses.

Normal CDF

Numerical integration and special-function approximations provide practical ways to evaluate the normal CDF despite the absence of an elementary antiderivative.

Final observation: For bounded Riemann-integrable functions, the Riemann and Lebesgue integrals agree. The Lebesgue framework is more general, while numerical methods make these mathematical concepts computationally accessible.
